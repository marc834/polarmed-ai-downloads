# PolarMed AI installer downloads

Knowledge pack zips that the PolarMed AI installer downloads when they are not next to the installer
package. The installer verifies each file against the SHA-256 recorded in its package before use.
File names carry the pack version; a published file is never replaced.

PolarMed AI is a prototype, not validated for clinical use. The packs have not been clinically reviewed.
